# CalloraX Play Store Release Checklist

- [ ] Create/verify unique Android package identity.
- [ ] Configure release signing and protect keystore.
- [ ] Build and test release AAB.
- [ ] Complete Play Console app details and screenshots.
- [ ] Publish a valid privacy policy URL.
- [ ] Complete Data Safety form truthfully.
- [ ] Declare sensitive/restricted permissions as required by current Play policy.
- [ ] Test account creation, email verification, password reset and account deletion.
- [ ] Test manual payment Pending/Approved/Rejected flow.
- [ ] Test Pro/Premium/Lifetime entitlement and ad-removal logic.
- [ ] Add production AdMob only after account/ad-unit setup; use test ads during development.
- [ ] Complete closed/open testing requirements applicable to the developer account.
- [ ] Review all third-party assets/licenses.
